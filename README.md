# 🤠 Cowboy Site

Personal blog & portfolio built with [Astro](https://astro.build).

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

```
src/
├── components/   # Reusable UI components
├── layouts/      # Page layouts
├── pages/        # Route pages & blog posts
└── styles/       # Global CSS
```

## 🚢 Deploy

Push to GitHub → Cloudflare Pages auto-deploys.

[![Deploy to Cloudflare Pages](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cowboy/cowboy-site)
